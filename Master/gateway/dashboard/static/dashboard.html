Body motion

Connect a robot to use its motions.

Walk, Run and Crawl

0–100% walks. Above 100% transitions to paired-leg Run; 200% is full Run.

Speed increases Run stride, leg lift, body bounding and requested cadence together. The saved joint speed limit slows the whole motion when needed, preserving its stride. Changes apply smoothly while moving. Finish settles the feet; Crawl remains crouched. Speed can cross between Walk and Run while moving. Finish before changing the selected gait or direction.
