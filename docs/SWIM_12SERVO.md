# Swim — twelve-servo handoff

Belly down on the floor, all four shoulders outward to 90°, four continuous breaststroke cycles with
overlapping front-arm and rear-leg motion, then replace the feet and return to standing.
Existing command: `{"t":"intent","name":"emote","asset":"swim"}`.
