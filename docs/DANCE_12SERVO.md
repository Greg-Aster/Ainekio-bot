# Dance — twelve-servo handoff

Five alternating left/right paired-leg beats with shoulder sway, body bob, roll
and twist; all four feet remain grounded, then the robot returns to standing.
Existing command: `{"t":"intent","name":"emote","asset":"dance"}`.
